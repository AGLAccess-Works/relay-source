# Relay 1.4 public beta 20 — quick start

Run the Setup executable, then open **Relay** from the Start menu. Relay opens maximised. The installer includes .NET and supports Windows 10 1809+ / Windows 11 x64. Connect your Xbox or Xbox Adaptive Controller using a connection that already works in Windows, then let go of all controls briefly.

## Set up your controls

Setup has four short steps: **Choose your controls**, **Help with reading**, **Typing and movement**, and **Ready to start**. Choose a controller, four switches, or switches with zoom pedals, then add the reading help you want. Bigger text, one input at a time, the Relay keyboard and single-button tools are selected to start. Extra choices are under **More help**. Practice and the full **Button guide** are optional. **Save and start** creates **My setup** and keeps existing profiles.

Throughout setup, **A selects, B goes next, X goes previous and Y goes back**. Switches assigned to those inputs can complete setup without a joystick or bumpers. A physical mouse or keyboard also works. The tools you choose become available after saving; setup does not start Narrator or Magnifier.

After saving, four-switch and pedal layouts keep A/B/X/Y as select, next, previous and back. Pedals use LT/RT for zoom. The controller layout uses the menu controls below. Select **Change my setup** on Control or Help to run setup again.

For the controller layout, press the D-pad to start menu navigation:

- D-pad: one navigation step per press. Holding does not repeat inside Relay.
- RB: next control. LB: previous control.
- A: select a button or tick a box. B: Escape / go back.
- Left stick: move the pointer everywhere, including the page list. Deliberate stick or physical mouse interaction returns buttons to pointer use.

With a keyboard, use Tab / Shift+Tab, arrows, Enter for buttons and Space for checkboxes. F6 moves between the page list and the page heading. This controller menu layout works inside Relay with Narrator off. In other apps, it works while Narrator is running and **Mapping → Scrolling → Use the D-pad to navigate menus** is enabled. Fixed switch and pedal profiles keep their own assignments.

See [Guided setup](GUIDED-SETUP.md) and [Using Relay with Narrator](NARRATOR.md).

## Find a page

The page list stays on the left: **Control, Mapping, Hardware, Profiles, Accessibility and Settings**, with **Help** and **About** below. Mapping and Accessibility have links to the secondary Pointer, Assistance and Scrolling pages. The existing Ctrl+1 through Ctrl+9 page shortcuts still work; Ctrl+Alt+H opens Hardware. See the shortcut table in the [Narrator guide](NARRATOR.md).

With the standard controller layout, press Right from the page list for the page heading, then Down for its controls. Use RB/LB to reach the next/previous control, including controls inside panels; B returns to pages. Fixed switch and pedal layouts use B for next, X for previous, A to select and Y to return.

With Narrator running, rest the pointer briefly on an item to hear it without clicking. **Accessibility → Read items under the pointer** controls this; turn it off if Windows already reads the item twice.

Control shows the controller, its connection, active profile and input assignments. Light and dark appearances use plain panels, clear dividers and outlined controls. Selecting an input on the picture or a text button opens its details; it does not run that action. Tab changes focus, Enter selects, and a physical press highlights activity without replacing your selection. **Change my setup** keeps setup within easy reach.

## Use an Adaptive starter

Open **Profiles**. Choose an **Accessibility starter profile**, read the instructions, then choose **Add starter profile**. The new copy is editable and your previous profiles remain available.

| Adaptive starter | Suggested setup |
| --- | --- |
| Adaptive: switches for menus | Switches in A/B/X/Y: select, next, previous, back. D-pad arrows; no joystick needed. |
| Adaptive: joystick and click switch | Compatible joystick in left USB; switch in A clicks or drags. B right-clicks, X/Y next/previous, D-pad slow pointer. |
| Adaptive: pedals for reading | Pedals in LT/RT zoom out/in once per press. Open Magnifier first. A/B/X/Y select, next, previous, back. |

These profiles use one button at a time and no vibration. Their meanings stay fixed with Narrator. Existing recorded accessories are carried into an Adaptive starter copy. The three starters are available in the dropdown on upgrades; completed profile libraries are not automatically filled with them.

Choose **Hardware → Identify an input**. Let go of all controls, then press or move only the accessory you want to name. Relay reports its Xbox input. Give it a helpful name, choose its type, and confirm the actual socket where you plugged it in. The input cannot tell Relay the physical socket.

**My saved accessories** opens the editor without starting identification. **Record input** is optional there. For more than one input, record each separately. Choose **Add another accessory** if needed, then **Save and close** once to keep everything. Cancel leaves your saved setup as it was. Desktop output pauses while recording; recording expires after 20 seconds.

Adaptive **Front view** and **Ports view** are available on Control and Hardware. They show your saved setup and matching logical input activity. Relay cannot automatically identify every accessory, confirm a physical plug or detect unplugging. If Xbox Accessories has remapped a socket, recording shows the Xbox input Relay receives.

In **Hardware**, choose the **Controller to use**, or select **Reconnect** to look again. Release every control after changing or reconnecting the device. **Controller layout** can identify known Xbox Adaptive hardware when Windows provides an unambiguous match. Choose the layout yourself when Windows hides the model or several controllers are connected. A manual choice changes the presentation, not your assignments or proof of the device's identity.

## Move and click on the desktop

These are the default mouse-mode controls. Your active profile can change them; Control shows the current assignments.

| Control | Default mouse-mode action |
| --- | --- |
| Left stick | Move the pointer |
| A / B / X | Left / right / middle click; hold to drag |
| D-pad | Move the pointer slowly when menu navigation is inactive; A clicks at that pointer |
| Right stick | Scroll |
| LB / RB | Precision / speed boost while held |
| LT / RT | Magnifier zoom out / in |
| Y | Close Magnifier |
| Left-stick press | Relay keyboard |
| Right-stick press | Relay accessibility tools |
| Menu / View | Windows Start / Windows accessibility settings, on release |
| View + Menu | Pause or resume |
| Ctrl + Alt + P | Pause or resume from the keyboard |

Release held buttons after changing modes or profiles. View+Menu remains reserved after remapping. The Xbox button is reserved by Windows. Pause before playing games.

While paused, you can still navigate Relay's own pages and settings windows. With four switches, use B/X to reach **Resume control** and A to select it. Paused controller output cannot type or operate Windows file dialogs. Let go of the controls before resuming.

## Type with Relay's keyboard

Select a text field in your app, then open Relay's **Keyboard**. Use the D-pad to choose a key and A to type. Y adds space, X erases, B hides, LT switches letters/numbers, RT selects Shift, and LB/RB move the text cursor. Move the left stick to use the mouse; the D-pad resumes key selection. The keyboard keeps your app's text field in focus. For fixed four-switch/pedal profiles, use B next key, X previous key, A type/select and Y hide; every key and keyboard control is reachable without a D-pad.

Shift, Ctrl, Alt and Windows apply to the next key only. Select a modifier again to cancel it. **Paste** pastes into the text field. **Voice** starts Windows voice typing, also available as a Windows+H mapping. Windows manages microphone permission and language setup. Keyboard selection temporarily replaces normal profile mappings and combinations.

## Adjust Relay

Open **Accessibility → Display and reading**. Options are shown directly beside **Theme**, **Text size**, **Interface spacing**, **Visual complexity** and **Focus display**. Move focus to explore; A or Enter applies an option. Each row identifies the selected option in text and through your screen reader.

Choose **Light** or **Dark**, **Standard / Reduced / Minimal** visual complexity, or stronger focus outlines without changing your other reading preferences. The quick theme action says **Use dark theme** or **Use light theme**; compact windows show **Dark theme** or **Light theme**.

**One control at a time (CVI simplified)** offers **Previous input** and **Next input** for inspecting inputs on Control, Mapping and Hardware. A position such as **Input 3 of 16** helps you keep your place. The full picture and duplicate input list stay hidden during activity refreshes. Minimal complexity also has a **Choose an input** button when one-control mode is off. These input choices show details without running the input's action.

Open **More display options** for display schemes, movement on screen, highlight colours, custom colours and restoring defaults. It starts closed. The seven schemes are Relay Default, Soft Light, Deep Dark, Maximum Contrast Light, Maximum Contrast Dark, CVI Simplified and Custom. Display scheme and highlight colour open named option buttons; A or Enter selects. **Cancel** or Escape keeps the saved value and returns focus. Use B for Back with the standard controller; fixed switch and pedal layouts use Y for Back, B for next and X for previous. Settings keeps the light/size quick controls and links to these options.

Text size offers 100% to 200%. Ctrl+plus / minus changes size; Ctrl+0 resets it. Pages reflow as text grows; the page list and page content scroll independently. At 200% in a small window, a smaller readable page title leaves room for the controls. Windows contrast colours take priority. **Restore Relay display defaults** keeps your text size and controller assignments. See [Make Relay easier to see](VISUAL-ACCESS.md) for custom colours and each setting.

From **Mapping**, open **Pointer** for speed, dead zone and smoothing. Increase the dead zone if the pointer moves at rest. **Scrolling** offers smooth scrolling, compatibility scrolling and one step per nudge. Vibration is optional. **Assistance** has movement stabilization and optional target help; Relay still leaves every click to you. See [Adaptive learning](ADAPTIVE-LEARNING.md) for local movement learning and its limits.

**Mapping** changes individual buttons and triggers: select an input, choose an action category, then choose its action. The assignment saves to your current profile. Expand **Button, trigger and keyboard shortcut options** for detailed editing, custom keyboard shortcuts, resets and combinations. See [Button combinations](BUTTON-COMBINATIONS.md).

In **Record keyboard shortcut**, use a physical keyboard to enter the shortcut. Temporary controller controls are A select, B next, X previous and Y cancel. After recording, select **Use shortcut** or **Cancel**. Controller A and Y do not record Enter or Escape as keys. Closing the window restores your previous controls and keeps desktop output paused if it was paused.

Changing pages keeps pointer movement active, including on Mapping, Hardware, Pointer, Assistance and Scrolling. Inside Relay, menu directions have one internal navigation owner and do not also inject Windows arrow keys. Fixed switch assignments for Tab, Shift+Tab, Enter, Escape and arrows remain usable. Diagram and tile selection only inspect an input; actual physical presses follow the current profile or navigation layout. Review the assignment before trying a changed mapping, and release controls after a profile or controller change.

**Accessibility** shows quick buttons for Windows tools, including Magnifier, Narrator, captions and voice typing. **More Windows tools and settings** holds the full searchable list of vision, hearing and interaction settings. Windows controls feature availability; opening a settings page does not toggle every setting on it. **Controller feedback** holds **Show controller labels**, **Reduce controller movement** and optional **Announce inputs while testing**. These detailed sections start closed. Spoken input names and actions remain available with extra labels off.

**Profiles** can copy, rename, import or export a controller setup. Changes save automatically to the active profile. Display schemes and visual preferences stay the same across profiles; they are separate from Adaptive accessory starters and button assignments. Upgrades and guided setup preserve your display choices, existing larger text and disabled pointer reading. Switching profiles releases held input and waits for neutral controls. Selecting a starter does not start Narrator or change Windows accessibility settings.

To switch profiles, open **Profile** in the header, or in the page list in a small window with large text. Explore the choices, then select with A, Enter or a click. **Cancel** keeps the current profile. On **Profiles**, focus lets you read each saved setup; select its button to activate it. Moving focus alone does not change your controls.

## Save and close

Closing Relay keeps control running in the notification area by default. Turn this off in Settings if you prefer. Double-click its tray icon to reopen, or use **Quit Relay** to exit fully. Startup at sign-in is optional and off by default.

Settings and error logs stay in `%LOCALAPPDATA%\XboxControllerMouse`. No accounts, telemetry or network calls are used. Uninstall through Windows Settings; saved settings remain available. Windows blocks Relay's simulated input on administrator windows and secure desktops. This unsigned beta may show a Windows publisher or SmartScreen notice.

See [Accessibility](ACCESSIBILITY.md) for supported controls and remaining acceptance checks. Automated checks do not establish flawless Narrator speech or replace physical Adaptive Controller testing.
