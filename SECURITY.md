# Security reporting

Relay is maintained by Alex Liddell / AGL Access Works.

Please report security concerns using [GitHub private vulnerability reporting](https://github.com/AGLAccess-Works/relay-source/security/advisories/new), rather than a public issue. Include the source commit or app version, Windows version, reproduction steps and impact. Do not include credentials, private profiles or personal information.

The [engineering audit](docs/ENGINEERING-AUDIT-2026-10-22.md) documents input injection, Windows integration, native library loading and remaining verification limits. Audit records describe the stated version and test environment; they do not certify future changes.
